# EditWeave 품질 기준셋

`korean-rough-cut.synthetic.json`은 한국어 AI 초벌 평가 파이프라인을 고정하기 위한 합성 기준셋이다. 군더더기·반복·무음의 시간 범위 정답과 오탐 방지 사례를 포함한다.

`shorts-multimodal.synthetic.json`은 대본만 강한 가짜 훅과 하이라이트·음성 에너지·얼굴 안정성·장면 경계 근거가 함께 있는 실제 훅을 구분하는 회귀 기준셋이다. 15·30·60초 후보가 같은 근거 구간을 선택하는지, 제외 훅을 피하는지, 추천 이유에 둘 이상의 비대본 신호가 포함되는지 측정한다.

`color-hdr-conformance.synthetic.json`은 검정·회색·흰색·RGB 원색 패치에서 sRGB 선형화, Rec.709→Rec.2020 변환, PQ·HLG 신호, 10-bit limited-range luma 코드, Rec.709 스코프 luma의 허용 오차를 고정한다. 이 기준셋은 수식과 회귀를 검증하지만 실제 GPU, 인코더, HDR 모니터 측정을 대체하지 않는다.

`audio-delivery-conformance.synthetic.json`은 Web 영상, EBU R128 방송, 팟캐스트 스테레오 프로파일에서 통합 LUFS와 dBTP 합격·실패 경계를 고정한다. 실제 완성 파일은 FFmpeg `ebur128` true-peak 모드로 다시 측정하며, 합성 사례는 방송 QC 장비와 청취 검수를 대체하지 않는다.

합성 데이터 통과는 실제 사용자 품질을 의미하지 않는다. 상용 판정에는 개인정보와 사용 권한을 확인한 50~100개 실제 영상의 분리된 `licensed-real` 기준셋이 필요하다. 실제 기준셋에는 채널·화자·성별이 아니라 다음 조건을 균형 있게 기록한다.

- 스튜디오·야외·카페·차량 등 소음 환경
- 단독·대화·인터뷰·강의·브이로그 발화 형식
- 표준어·일상 구어·빠른 말·코드 스위칭
- 휴대전화·핀 마이크·카메라 내장 마이크
- 쇼츠 후보의 대본 훅·음성 에너지·얼굴 가시성·장면 전환 조합

보고 지표는 한국어 CER/WER, 군더더기·반복·무음의 precision/recall/F1, 시간 IoU, 편집자 후보 채택률, 원본 10분당 수정 시간이다. 원본 음성·대본·평가자 식별 정보는 저장소에 커밋하지 않는다.
