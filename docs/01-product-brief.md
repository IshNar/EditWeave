# 01. 제품 개요

## 제품 정의

Cutline은 롱폼 유튜브 영상과 세로형 쇼츠를 함께 제작하는 편집자를 위한 크로스플랫폼 데스크톱 영상 편집기다. 범용 후반작업 도구를 그대로 복제하지 않고, 촬영 원본에서 초벌 컷·자막·쇼츠 후보를 빠르게 만드는 작업에 집중한다.

핵심 약속은 다음 한 문장으로 표현한다.

> 긴 촬영 원본을 가져오면, 대본을 읽듯 초벌 편집하고 같은 프로젝트에서 롱폼과 쇼츠를 완성한다.

## 지원 콘텐츠

| 콘텐츠 | 기본 화면비 | 주요 작업 |
| --- | --- | --- |
| 유튜브 롱폼 | 16:9 | 컷 편집, B-roll, 자막, BGM, 음량 정리 |
| Shorts/Reels/TikTok | 9:16 | 자동 리프레임, 강조 자막, 빠른 전환 |
| 피드/광고 소재 | 1:1, 4:5 | 안전 영역, 짧은 카피, 버전 출력 |
| 팟캐스트/인터뷰 | 16:9, 9:16 | 화자 감지, 멀티캠, 하이라이트 추출 |

화면비는 별도 편집 엔진이 아니라 하나의 시퀀스 속성으로 취급한다. 동일 원본을 공유하면서 롱폼 시퀀스와 쇼츠 시퀀스를 따로 만들 수 있어야 한다.

## 우선 사용자

1. 매주 1개 이상의 영상을 제작하는 1인 유튜버
2. 여러 채널을 담당하며 반복 컷·자막 작업이 많은 편집자
3. 롱폼에서 쇼츠를 함께 납품하는 소규모 제작팀

## 해결할 문제

- 침묵, 말실수, 반복 문장을 사람이 처음부터 끝까지 찾아야 한다.
- 한국어 자막 생성 후 교정과 스타일링에 시간이 많이 든다.
- 롱폼을 만든 뒤 쇼츠용 구간을 다시 탐색하고 세로 구도를 잡아야 한다.
- 기존 전문 편집기는 강력하지만 초보자에게 패널과 설정이 과도하게 많다.
- 간편 편집기는 빠르지만 긴 프로젝트, 파일 관리, 세밀한 타임라인 작업이 약하다.

## 제품 원칙

- 비파괴 편집: 원본 파일은 절대 수정하지 않는다.
- 빠른 첫 결과: 가져오기 후 5분 이내에 초벌 컷을 확인한다.
- AI는 제안자: 자동 편집 결과는 항상 되돌리고 수정할 수 있다.
- 키보드 우선: 반복 컷 작업은 마우스 없이도 가능하게 한다.
- 로컬 우선: 미디어와 프로젝트는 기본적으로 사용자 컴퓨터에 둔다.
- 교환 가능성: Premiere Pro와 DaVinci Resolve로 넘길 수 있는 경로를 제공한다.

## 경쟁 제품에서 참고할 것

- Premiere Pro: 미디어/프로그램 모니터/인스펙터/타임라인의 익숙한 배치
- CapCut: 자동 자막과 프리셋을 빠르게 적용하는 흐름
- DaVinci Resolve: 작업 목적에 따라 복잡도를 단계적으로 노출하는 방식
- Vrew: 대본을 수정하면 컷과 자막이 함께 바뀌는 경험
- ComfyUI: 필수 편집 엔진이 아니라 고급 사용자가 명시적으로 선택한 이미지 처리만 외부 로컬 워크플로로 확장하는 방식

특정 제품의 화면을 그대로 복제하지 않는다. 친숙한 편집 개념은 유지하되, 정보 구조와 시각 디자인은 독자적으로 만든다.

## 성공 지표

- 60분 토킹헤드 영상의 첫 초벌 컷 생성 시간
- 자동 자막 생성 후 사용자가 수정한 단어 비율
- 롱폼에서 첫 쇼츠 초안까지 걸린 시간
- 재생 중 프레임 드롭과 오디오 싱크 오차
- 앱 충돌 후 복구 성공률
- 첫 사용자가 도움말 없이 영상 하나를 출력하는 비율
