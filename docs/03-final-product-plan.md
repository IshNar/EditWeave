# 03. 최종 제품 계획

> 현재 소스 상태: 전체 출시 제품 개발. 기능 코드 존재만으로 완료 처리하지 않으며, 실무 작업 완주와 안정화 조건은 [실무용 완성품 전환 계획](08-production-completion-plan.md)에서 추적한다. 기술 버전 번호는 프로젝트 호환성과 업데이트를 위한 식별자일 뿐 기능 범위를 나누지 않는다.

## 최종 목표

Windows와 macOS에서 동작하며, 롱폼과 쇼츠의 전체 제작 흐름을 한 프로젝트에서 처리하는 안정적인 데스크톱 편집기를 제공한다.

## 전체 출시 기능

### 미디어와 프로젝트

- 영상, 오디오, 이미지, 자막 가져오기
- 폴더·태그·검색·사용 여부 표시
- 미디어 오프라인 감지와 재연결
- 자동 저장, 버전 기록, 충돌 복구
- 프록시 및 캐시 위치·용량 관리

### 편집

- 다중 비디오·오디오·자막 트랙
- 선택, 삽입, 덮어쓰기, 트림, 롤, 슬립, 리플 편집
- 마커, 스냅, 링크 선택, 그룹
- 일정 속도, 키프레임 속도 램프, 역재생, 정지 프레임, 기본 트랜지션
- 로컬 장면 전환 감지, 후보 검토, 마커 또는 컷 적용
- 위치·크기·회전·불투명도 키프레임
- 중첩 시퀀스와 조정 레이어

### 오디오

- 음량, 페이드, 패닝, 음소거·솔로
- 음성 노멀라이즈, 노이즈 감소, 음성 강조
- BGM 자동 덕킹
- 피크 미터와 클리핑 경고

### 자막과 텍스트

- 한국어 중심 음성 인식
- 단어 단위 강조 자막
- 자막 교정 사전과 고유명사 사전
- SRT, VTT 가져오기·내보내기
- 브랜드 자막 프리셋

### 쇼츠

- 9:16, 1:1, 4:5 파생 시퀀스
- 얼굴·화자 추적 기반 자동 리프레임
- 플랫폼 안전 영역과 자막 충돌 경고
- 하이라이트 후보 및 여러 길이 버전

### 색상과 효과

- 노출, 대비, 화이트밸런스, 채도
- LUT 적용
- 크롭, 블러, 그림자, 기본 마스크
- 배경 제거와 얼굴 모자이크
- 선택 이미지를 사용자가 명시적으로 연 로컬 ComfyUI 워크플로에 보내고 결과를 새 미디어로 받는 선택적 확장 연결

### 출력과 호환

- H.264, H.265 및 플랫폼별 하드웨어 인코딩
- 해상도·프레임레이트·비트레이트 프리셋
- YouTube 롱폼·Shorts 출력 프리셋
- 일괄 출력과 백그라운드 렌더 큐
- Premiere/Resolve 교환을 위한 FCPXML/EDL 및 자막 내보내기

## 전체 출시 범위에 포함하는 확장 기능

- 타임코드·클랩 메타데이터 멀티캠 동기화와 자동 화자 전환
- 현재 로컬 타임코드 코멘트를 확장한 공유 검토 링크와 온라인 댓글 동기화
- 팀 프로젝트 잠금과 변경 병합
- 플러그인 SDK
- 템플릿 마켓과 브랜드 키트
- AI B-roll 검색·생성
- 음성 더빙과 다국어 립싱크는 별도 동의가 있는 경우에만 제공

## 단일 완료 기준

- 단계별 후보나 축소판을 별도 완료로 선언하지 않는다.
- 미디어 가져오기부터 편집·색상·오디오·자막·교환·복구·납품·설치까지 전체 흐름을 하나의 출시 기준으로 관리한다.
- 구현되지 않은 확장 기능도 별도 V2로 미루지 않고 전체 출시 백로그에서 계속 개발한다.
- 패키지의 SemVer는 파일 형식·업데이트 호환성과 배포 추적에만 사용한다.

## 최종 품질 기준

- 지원 포맷 목록을 자동화된 미디어 샘플로 회귀 테스트한다.
- 저장 중 앱이 종료되어도 마지막 자동 저장 시점으로 복구한다.
- 장시간 렌더 실패 시 원인과 재시도 방법을 사용자에게 보여준다.
- 클라우드 AI 기능은 업로드 파일, 보관 기간, 삭제 방법을 명시한다.
- 미디어 파일을 삭제하거나 덮어쓰는 기능은 명시적 확인 없이 실행하지 않는다.
