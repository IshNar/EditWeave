# 05. GUI 가이드

## 기준 제품

Premiere Pro를 유일한 기준으로 삼지 않는다. 다음 세 가지 장점을 조합한다.

| 참고점 | 적용 방식 |
| --- | --- |
| Premiere Pro의 익숙한 공간 배치 | 왼쪽 소스, 중앙 미리보기, 오른쪽 속성, 아래 타임라인 |
| CapCut의 빠른 접근성 | 자막·화면비·AI 도구를 한두 번의 클릭으로 실행 |
| DaVinci Resolve의 단계적 복잡도 | 초벌, 편집, 자막, 출력 작업을 필요할 때만 확장 |

Premiere의 복잡한 패널 시스템과 작은 아이콘 밀도를 그대로 가져오지 않는다. 첫 화면에서 사용자가 해야 할 다음 행동이 보이도록 한다.

## 기본 화면

```text
┌ 프로젝트/저장 ───────── 실행취소 ───── 화면비 ─── 내보내기 ┐
├ 미디어·대본 ┬──────── 미리보기 ────────┬ 클립 속성 ┤
│             │                           │           │
│             │                           │           │
├─────────────┴───────────────┬───────────┴───────────┤
│ 도구/재생                   │ 타임라인 확대·축소    │
├ 트랙 헤더 ┬────────────────────────────────────────┤
│ 비디오    │ 클립   클립          클립              │
│ 오디오    │ 파형                                      │
│ 자막      │ 문장        문장                         │
└───────────┴─────────────────────────────────────────┘
```

## 상호작용 원칙

- 선택된 대상은 미리보기, 타임라인, 속성 패널에서 같은 강조색을 사용한다.
- 파괴적 작업보다 실행 취소 가능성을 우선 보여준다.
- 재생과 컷 편집에 필요한 버튼은 타임라인 가까이에 둔다.
- 화면비는 프로젝트 생성 후에도 바꿀 수 있으나, 기존 위치가 잘릴 수 있음을 표시한다.
- AI 제안과 확정 편집은 색과 상태로 구분한다.
- 아이콘만 있는 버튼은 툴팁과 접근성 이름을 제공한다.

## 쇼츠 모드

- 세로 캔버스를 단순히 중앙에 작게 표시하지 않고 가용 높이를 최대한 사용한다.
- 자막·사용자명·플랫폼 버튼과 충돌하는 안전 영역을 오버레이로 제공한다.
- 얼굴 추적 구도를 미리보기에서 직접 수정할 수 있게 한다.
- 롱폼 원본 시퀀스와 쇼츠 파생 시퀀스의 관계를 표시한다.

## 색과 밀도

- 배경은 긴 편집 작업에 적합한 저채도 다크 테마를 기본으로 한다.
- 보라색 계열은 선택·현재 작업, 민트 계열은 정상·완료 상태에 사용한다.
- 오류는 붉은색만으로 전달하지 않고 아이콘과 문장을 함께 사용한다.
- 최소 클릭 영역은 32px, 주요 버튼은 36px 이상으로 한다.

## 주요 단축키 초안

| 동작 | 단축키 |
| --- | --- |
| 재생/정지 | Space |
| 재생 헤드에서 분할 | S |
| 선택 삭제 | Delete / Backspace |
| 실행 취소 | Ctrl/Cmd + Z |
| 다시 실행 | Ctrl/Cmd + Shift + Z |
| 타임라인 확대/축소 | Ctrl/Cmd + `+` / `-` |

Premiere 단축키 프리셋을 나중에 제공하되 기본 단축키는 초보자가 추측하기 쉬운 구성을 사용한다.
