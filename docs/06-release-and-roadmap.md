- 기술 버전: 0.1.0 (호환성·업데이트 식별자)

## 전체 출시 체크리스트

1. 10분 토킹헤드 원본으로 편집자 3명이 가져오기→AI 초벌→쇼츠→출력을 완주한다.
2. 합성 10/30/60분 타임라인 편집 연산 기준선은 완료했다. iPhone/Android VFR 실물 샘플과 실제 30/60분 소스에서 A/V 동기화·디코딩·메모리를 측정한다.
   프로그램 재생 헤드는 monotonic 시계와 외부 탐색 재기준화를 사용하며, 정지 상태 프레임 정확 seek·metadata 지연 seek·재생 중 audio hard correction과 video soft/hard drift correction을 구현했다. 실제 장시간 drift 수치는 아직 사용자 측정 전이다.
3. Whisper 최초 모델 다운로드와 캐시 재사용은 검증 완료. 긴 한국어 음성 정확도와 화자 분리는 계속 검증한다.
4. 960px·30fps 실제 편집 프록시, 데스크톱 영속 캐시·재열기 복원·개별 정리, 256MB 초과 영상의 파일 범위 읽기와 FFmpeg 보조 경로를 구현했다. 실제 1.5GB 초과 스마트폰·전문 코덱에서 메모리·취소·재연결을 검증한다.
5. macOS Apple Silicon 빌드, Developer ID 서명, 공증을 macOS CI/장비에서 검증한다.
6. Windows 코드 서명과 macOS 공증은 인증서가 있는 배포 환경에서 수행한다. 업데이트 클라이언트의 HTTPS·Ed25519 서명 매니페스트 검증, OS/CPU 대상 일치, 서명 payload 기반 네이티브 다운로드·SHA-256·Authenticode/Developer ID·게시자 재검증·1회 실행 토큰, 재시작 버전 확인·기존 파일 안전 재시도와 별도 릴리스 생성·서명 도구를 구현했다. 공개 키로 플랫폼별 catalog와 artifact를 시작 전 확인하고 무압축 Range 스트리밍하는 Node/Docker 업데이트 서버도 구현했다. 익명 충돌 수집은 명시 동의·로컬 큐·재시도와 보존 한도가 있는 수집 서버까지 구현했으며 두 서비스의 실제 운영 URL·TLS·암호화 볼륨을 연결한다.
7. 태그/수동 SemVer를 package·Tauri·Cargo에 동기화하고 matrix platform별 매니페스트 URL, 공개 키·key ID와 실제 앱 버전을 Vite/Rust 빌드에 함께 넣는 CI 릴리스 래퍼를 구현했다. 운영 변수 일부만 설정된 빌드는 실패시켜 업데이트를 잘못 구성한 설치 파일 생성을 막는다.

## 전체 출시 핵심 개발 반영

- 다중 트랙 삽입/덮어쓰기, 고급 트림, 링크·그룹, 마커를 구현했다.
- 공유 master의 실제 pre/post 처리 stereo 신호를 읽는 L/R dBFS 미터, 전체 채널 sample peak 분석 기반 -1 dBFS 정규화, 덕킹·soft-open 노이즈 게이트·음성 강조·3밴드 EQ·Dynamics·LUFS 예상 트랙 믹서를 구현했다. 미터는 처리 후 L/R peak와 soft clip 직전 과부하 hold를 표시한다. 정규화, 게이트, RBJ Biquad high-pass/EQ/voice enhance, dB compressor와 brickwall limiter는 미리보기·Aux·출력·Delivery Guard가 같은 파라미터 계약을 사용한다. 미리보기의 모든 클립은 공유 역할 버스에 먼저 합산된 뒤 버스 삽입·gain·안전 ceiling·master tanh를 거쳐 최종 출력과 처리 순서를 맞춘다.
- Web Audio StereoPanner와 같은 mono/stereo pan 공식을 최종 PCM에 적용해 stereo center에서 좌우를 unity로 유지하고, Quad·5.0/5.1 speaker layout은 표준 stereo downmix 후 pan한다. 7.1 이상 원본은 추가 rear/height 채널이 현재 stereo 납품에 보존되지 않음을 사전 경고한다.
- 역재생 오디오는 Mediabunny로 250ms 범위 PCM을 디코딩하고 출력과 같은 속도 곡선 적분 source-time으로 재표본화해 공유 clip/bus DSP graph에 최대 0.9초 앞까지 예약한다. 재생 진입 1.25초 전 준비, 탐색/루프 재기준화와 반복 underrun 오류 표시를 구현했으며 실제 긴 GOP·고배속 원본 검증이 필요하다.
- 속도 변경 음정 유지는 기본 활성화되며 정·역방향 미리보기와 최종 출력이 40ms grain·10ms hop, ±6ms 상관 정렬, 50ms 결정적 pre-roll의 공통 overlap-add PCM을 사용한다. 25% 미만·400% 초과는 Delivery Guard가 grain 질감 확인 대상으로 표시한다.
- 변형/시각 효과 키프레임, 트랜지션, 색보정, 소스 스코프, LUT, 일정 속도·키프레임 속도 램프·역재생·정지 프레임을 구현했다.
- 소스 I/O·3점 편집, J/L 컷, 슬라이드 트림, 중첩 시퀀스, 파형 멀티캠, 사용자 단축키를 구현했다.
- 선택 클립의 로컬 장면 전환 감지와 후보별 마커/분할 검토 흐름을 구현했다.
- Creator Source Graph, Transcript Edit Contract, Delivery Guard와 로컬 타임코드 검토 CSV를 구현했다.
- 로컬 화자 라벨·수동 교정, 단어 강조 자막, 교정 사전과 브랜드 프리셋을 구현했다.
- 얼굴 표본 추적 자동 리프레임과 안전 영역 충돌 경고를 구현했다.
- H.265/하드웨어 인코딩 선택, 30초 완결 MP4 체크포인트와 앱 재실행 후 재개·무재인코딩 결합, 쇼츠 완료 파일 단위 재개, FCPXML/EDL 교환을 구현했다.
- HEVC Main10 PQ/HLG 10-bit 출력, 효과 없는 동일 크기 raw retimestamp, 단일/복수 raw I420P10 원본의 공간 변형·색상·곡선·Qualifier·노드·마스크·블러·그림자·추적 모자이크·크로마키·합성 모드와 조정 레이어를 처리하는 RGBA16F WebGPU 합성, HDR10 `mdcv`/`clli` 보존을 구현했다. 비표준 HDR 입력과 회전·흰색 전환의 Canvas 경계 조합은 실제 장비 납품 비교가 남아 있다.
- 업로드 없는 LAN 검토 링크와 브라우저 MP4 Range 재생·코멘트 양방향 병합, 자동 저장 버전 비교·새 분기 가져오기, 공유 프로젝트 lock/heartbeat와 선언형 Creator Pack을 구현했다.
- React/window/Promise 충돌을 사용자 동의 뒤에만 HTTPS endpoint로 보내는 최대 10개 로컬 큐와 지수 backoff, 이중 민감 정보 제거, 날짜별 JSONL·중복 제거·속도 제한·30일/512MB 보존 한도의 Node/Docker 수집 서버를 구현했다. 실제 운영 endpoint와 TLS·저장 볼륨은 아직 설정되지 않았다.

사용자 실제 실행에서 시작 오류와 미디어 가져오기 장애가 발견되어 “기능 추가 완료” 판정을 철회했다. 현재는 실무 흐름을 막는 기능 공백과 부분 구현을 계속 개발하고, 그 다음 사용자 회귀 테스트·실물 미디어 호환성·서명·공증·운영 서버·최신 패키징을 완료한다. 세부 기준은 `08-production-completion-plan.md`에서 관리한다.

이 문서는 구현 범위와 출시 품질을 구분하기 위한 기준이다. UI에 버튼이 존재하는 것만으로 전체 출시 완료로 판단하지 않는다.

## 2026-08-08 개발 이력

- 실제 로컬 Whisper tiny 최초 다운로드와 캐시 재사용을 통과했다.
- H.264/AAC MP4와 MP3를 자동 검사하는 첫 미디어 호환성 매트릭스를 추가했다.
- 미디어별 디코더 가능 여부와 장시간·고해상도 경고를 UI에서 확인할 수 있다.
- 최대 240개 영상 패킷의 프레임 지속 시간 분산으로 VFR 가능성을 진단하고 CFR/VFR 합성 회귀 테스트를 추가했다.
- 10/30/60분 합성 타임라인(1,200/3,600/7,200클립)의 리플 삭제와 직렬화 기준선을 측정했다. 실제 미디어 디코딩·렌더 성능을 뜻하지는 않는다.
- 960px·고정 30fps H.264/AAC 프록시 생성, 진행률, 취소, 원본/프록시 전환을 구현했다. 프록시는 미리보기에만 적용하고 출력은 원본을 유지한다.
- Tauri 앱 캐시에 프록시를 영속 저장하고 프로젝트 재열기 복원·오프라인 원본 상태의 프록시 미리보기·개별 삭제를 구현했다. 브라우저 모드는 세션 전용이다.
- 이후 전체 출시 소스에서 대용량 스트리밍 프록시와 전문 편집 기능을 계속 구현했다. 기능 공백과 발견 버그는 버전 단계로 미루지 않고 같은 출시 범위에서 수정한다.
