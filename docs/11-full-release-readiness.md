# 11. 전체 출시 대비 현황 보고서

- 기준일: 2026-08-10
- 대상 제품: Cutline 데스크톱 영상 편집기
- 목표: 단계별 프로토타입·V1·V2가 아닌 **전체 출시 제품**
- 평가 기준: 현재 작업 폴더의 소스와 기존 개발 기록
- 이번 문서 작성 중 실행한 것: 문서·소스 구조 확인
- 이번 문서 작성 중 실행하지 않은 것: 앱 실행, 버튼 조작, 테스트, 타입 검사, 빌드, 패키징, 실제 미디어 재검증

## 결론

현재 Cutline은 단순 시연용 프로토타입을 넘어, 전문 영상 편집기의 주요 작업 흐름이 소스에 폭넓게 연결된 상태다. 미디어 관리, 멀티트랙 편집, 트랜지션, 색상·효과, 오디오, 자막·AI, 쇼츠 파생, 렌더 큐, 프로젝트 복구, 교환·검토, 설치·업데이트 기반까지 구현 범위가 존재한다.

그러나 **전체 출시 준비 완료 상태는 아니다.** 또한 현재 상태를 **Premiere Pro 동급 완성품**이라고 선언할 수도 없다. 가장 큰 이유는 다음과 같다.

1. 사용자가 실제 환경에서 미디어 로딩 실패, MOV 로딩 실패, 미디어 삭제·이동 실패를 확인했다.
2. 해당 문제를 보완하는 소스 경로는 추가됐지만, 사용자 요청에 따라 수정 후 실행 검증은 하지 않았다. 따라서 `수정 코드 존재`이지 `동작 완료 확인`은 아니다.
3. 장시간 프로젝트, 다양한 MOV 내부 코덱, VFR, HDR, 전문 카메라 원본, GPU·메모리·A/V 동기화의 실물 결과가 확정되지 않았다.
4. Windows 코드 서명, macOS 빌드·서명·공증, 운영 업데이트·충돌 수집 인프라가 출시 환경과 연결되지 않았다.
5. Adobe 생태계 전체와의 동급성을 의미하는 플러그인, 하드웨어, 협업, 교환 포맷 범위까지 완성된 것은 아니다.

`package.json`의 `0.1.0`은 패키지 호환성과 업데이트를 위한 기술 식별자다. 이 번호를 이유로 개발 범위를 V1 수준에 제한하지 않는다. 앞으로도 버전별로 기능을 미루는 방식이 아니라, 아래의 전체 출시 차단 항목을 모두 닫는 방식으로 진행해야 한다.

| 전체 출시 | **미완료** | 핵심 차단 문제와 외부 출시 조건을 모두 해결해야 함 |

## 소스 기준 완료된 범위

아래 항목은 현재 소스에 사용자 명령과 처리 경로가 존재한다는 뜻이다. 실제 사용자 환경에서 출시 품질까지 확인됐다는 뜻은 아니다.

### 1. 미디어와 프로젝트

- 파일 선택, HTML 드롭, Tauri 네이티브 경로 드롭, 다중 가져오기
- MP4, MOV/QT, MKV, MXF, AVI, 오디오, 이미지와 이미지 시퀀스 확장자 판별
- 미디어 메타데이터, 썸네일, 파형, VFR, HDR, 타임코드·릴 분석
- 직접 디코딩이 어려운 영상·오디오·이미지의 호환 프록시 생성 경로
- 대용량 원본의 범위 읽기, 데스크톱 프록시 캐시, 원본/프록시 전환
- 오프라인 미디어 표시, 자동·수동 재연결, 소스 해석, 메타데이터 CSV
- 프로젝트 저장·열기, 자동 저장 이력, 최근 프로젝트, 프로젝트 잠금
- 시퀀스 생성·복제·삭제 보호, 분기·병합·충돌 결정
- 미디어 빈과 폴더, 다중 선택, 이동·정리, 사용 중인 원본 보호 제거 경로
- 렌더 큐가 참조하는 시퀀스·중첩 시퀀스·미디어 스냅샷 보호

### 2. 편집과 타임라인

- 멀티트랙 영상·오디오·텍스트 타임라인과 트랙 대상 지정
- 삽입, 덮어쓰기, 교체, Fit to Fill, Lift, Extract, 공백 닫기
- 이동, 스냅, 분할, 링크·그룹, 마커, 복사·붙여넣기와 속성 붙여넣기
- 일반·리플·롤·슬립·슬라이드·속도 스트레치 트림
- 소스 모니터 I/O와 3점 편집, J/L 컷
- 중첩 시퀀스, 멀티캠, 파형 동기화, 조정 레이어
- 일정 속도, 속도 램프, 역재생, 음정 유지, 정지 프레임
- 변형·효과·오디오 자동화 키프레임과 Undo/Redo 경로

### 3. 트랜지션과 프리셋

- 영상·오디오 트랜지션 적용, 제거, 길이·정렬·이징 편집
- 타임라인 핸들 조절, 키보드 선택·삭제, 복사·붙여넣기
- 시퀀스별 기본 영상·오디오 트랜지션과 기본 적용 단축키
- 선택 클립과 링크된 A/V 경계의 일괄 적용
- 트랜지션 프리셋 저장, 검색, 즐겨찾기, 정렬, 이름 변경, 복제
- 프리셋 가져오기·내보내기와 Creator Pack 연결
- OTIO, Premiere XML, FCPXML, EDL 교환 시 트랜지션 정보 보존 경로

### 4. 영상 효과와 색상

- 위치, 크기, 회전, 크롭, 불투명도, 합성 모드
- LUT, 기본 그레이딩, 색상 곡선, HSL Qualifier, 자동 화이트밸런스·매치
- 색상 노드 그래프, 마스크, 크로마키, 블러, 비네트, 그림자

- 장면 전환 감지, 조정 레이어, 효과·모션·속도·타이틀 템플릿
- 색상 스코프, SDR 톤매핑, PQ/HLG와 HDR10 메타데이터 처리 경로

### 5. 오디오와 녹음

- 클립·트랙 gain/pan, EQ, gate, dynamics, limiter, 정규화
- 역할 버스, Aux, 삽입 체인, master L/R 미터와 loudness 측정
- 오디오 페이드·커브, 자동화, 스템 출력
- 음성 녹음·ADR 큐·다중 테이크·컴핑·영속 저장
- 속도 변경·역재생 오디오와 음정 유지 처리 경로
- 녹음 권한은 마이크만 요청하며 카메라 영상은 요청하지 않도록 구성

### 6. 자막, AI, 쇼츠

- 로컬 전사, 화자 라벨, 사용자 교정, 교정 사전

- AI 데이터 로컬 처리·개인정보 설정 경로

### 7. 출력, 복구, 교환, 검토

- H.264/H.265 MP4, 데스크톱 ProRes/DNxHR MOV, WAV·스템 출력 경로
- 전체, In/Out, 선택 클립, 사용자 범위 출력
- 렌더 큐, 일시정지·재개·재시도, 체크포인트 복구, 쇼츠 일괄 출력

- LAN 검토 링크, 코멘트 병합, 프로젝트 버전 비교·3-way 병합

## 최근 사용자 보고 문제의 현재 상태

| 문제 | 소스에서 반영한 대응 | 현재 판정 |
| --- | --- | --- |
| 일반 파일 로딩 실패 | 확장자·MIME 판별, 분석 실패 처리, 디코딩 가능성 확인, 호환 프록시 대체 경로 | **검증 전 / 출시 차단** |
| MOV 로딩 실패 | `.mov`·`.qt`·`video/quicktime` 수용, 내부 스트림 분석, 실패 시 FFmpeg 기반 호환 프록시 경로 | **검증 전 / 출시 차단** |
| 기존 미디어 삭제 실패 | 단일·다중 제거, 타임라인 참조 정리, 렌더 작업 참조 보호와 사용자 확인 경로 | **검증 전 / 출시 차단** |
| 미디어 빈 이동 실패 | 폴더 생성, 드롭·일괄 이동, 다중 선택 이동 경로 | **검증 전 / 출시 차단** |
| 카메라 접근 우려 | ADR·보이스오버는 `video: false`인 마이크 전용 권한이며 카메라 권한을 거부하도록 구성 | 소스 반영 / 실행 확인 전 |

이 표의 네 가지 핵심 동작이 실제 앱에서 통과하기 전에는 다른 고급 기능이 많더라도 전체 출시 완료로 볼 수 없다.

## 아직 미비한 점

### 1. 미디어 호환성

- MOV는 컨테이너이므로 H.264, HEVC, ProRes, 알파 채널, PCM 등 내부 코덱 조합에 따라 결과가 달라진다. 확장자를 받는 것만으로 호환이 완료되지는 않는다.
- iPhone·Android VFR, 화면 녹화 파일, 전문 카메라 원본, 긴 GOP, 10-bit 4:2:2, 손상·불완전 파일의 실제 동작이 보장되지 않았다.
- 대용량 파일 가져오기 취소, 분석 재시도, 오프라인 전환, 프록시 생성 실패 후 복구가 장시간 사용에서 확인되지 않았다.
- R3D, BRAW, ARRIRAW 등 전문 RAW 포맷의 네이티브 색상 관리·디베이어를 완성했다고 볼 근거가 없다.

### 2. 편집 정확성과 장시간 안정성

- 고급 트림, 링크·그룹, ADR 보호, 중첩, 속도 램프가 복합된 실제 프로젝트의 프레임 정확성과 Undo/Redo 무결성이 확정되지 않았다.
- 10/30/60분 실물 프로젝트의 메모리 증가, 탐색 지연, 오디오 드리프트, 프레임 드롭, 캐시 정리가 출시 기준에 도달했는지 알 수 없다.
- 미리보기와 최종 출력의 모든 효과·블렌드·마스크·속도·오디오 조합이 동일하다는 비교 증거가 부족하다.

### 3. 색상, HDR, 모니터링

- WebGPU와 HEVC Main10 지원 여부가 장비마다 다르며 GPU별 결과가 확정되지 않았다.
- 전문 기준의 색상 관리, 디스플레이 변환, HDR 휘도·메타데이터, 스코프 정확도를 외부 기준 장비와 비교하지 않았다.
- 방송 모니터 출력, SDI/NDI 장치, 외부 비디오 I/O는 완성된 범위로 확인되지 않는다.

### 4. 오디오

- mono/stereo/5.1/7.1 이상의 실제 채널 매핑, 다운믹스, 위상, loudness, True Peak를 기준 측정기와 비교하지 않았다.
- VST 등 제3자 오디오 플러그인 생태계와 전문 제어 표면 지원은 확인되지 않는다.
- ADR 장시간 녹음, 장치 전환, 샘플레이트 불일치, 권한 거부·복구 흐름이 출시 품질로 확정되지 않았다.

### 5. AI와 자막

- 긴 한국어·혼합 언어·소음 환경의 전사 정확도, 화자 분리, 취소·재개, 모델 배포 용량이 확정되지 않았다.
- AI 초벌·하이라이트·자동 리프레임은 제안 기능이며, 결과 정확도와 편집자 수정 흐름을 더 다듬어야 한다.
- 방송 자막 표준과 접근성 요구 전체를 충족한다고 선언할 수 없다.

### 6. 교환, 협업, 생태계

- Premiere XML, FCPXML, OTIO, EDL은 각 NLE의 모든 효과·키프레임·속도·색상·오디오 속성을 완전 왕복하지 못할 수 있다.
- AAF/OMF, After Effects Dynamic Link, Adobe 플러그인·MOGRT 전체 호환, 광범위한 서드파티 패널 생태계는 완성 범위로 확인되지 않는다.
- LAN 검토는 로컬 네트워크 중심이며 인터넷 협업, 권한 관리, 영구 세션, 대규모 팀 프로젝트 운영은 별도 완성이 필요하다.

### 7. 배포와 운영

- Windows 설치 파일의 Authenticode 코드 서명이 없다.
- macOS Apple Silicon 실기기 빌드, Developer ID 서명, 공증, Gatekeeper 설치가 남아 있다.
- 실제 업데이트 도메인·TLS·서명 키 운영, 충돌 수집 저장소·접근 제어·보존 정책이 연결되지 않았다.
- 개인정보 처리방침, 라이선스, 오픈소스 고지, 지원 정책, 장애 대응 절차, 릴리스 노트 체계가 제품 출시물로 완결되지 않았다.
- 다국어 UI, 접근성, 키보드 탐색, 고해상도·다중 모니터·저사양 환경 대응 수준이 확정되지 않았다.

## 반드시 해야 할 일

다음은 버전 단계가 아니라 **전체 출시 차단 우선순위**다.

### P0 — 출시를 막는 핵심 작업

1. **미디어 가져오기 완결**
   - 실제 실패 MOV와 일반 영상이 선택·드롭 양쪽에서 등록돼야 한다.
   - 원본 직접 디코딩 또는 호환 프록시 생성 중 하나가 반드시 성공해야 한다.
   - 실패 시 파일명, 컨테이너, 코덱, 실패 단계와 사용자가 취할 조치를 표시해야 한다.

2. **미디어 삭제·이동 완결**
   - 단일·다중 선택, Delete/Backspace, 메뉴 제거, 폴더 이동이 실제로 반영돼야 한다.
   - 타임라인·중첩·ADR·렌더 큐가 참조 중이면 손상 없이 차단하거나 명시적 정리 후 제거해야 한다.
   - 앱 재실행 뒤에도 빈 구조와 제거 결과가 유지돼야 한다.

3. **프로젝트 무결성 완결**
   - 저장, 종료, 재실행, 자동 재연결, 수동 재연결, 자동 저장 복구가 데이터 손실 없이 이어져야 한다.
   - 중첩, 멀티캠, 자막, 키프레임, 프록시, ADR, 렌더 큐 참조가 저장 전후 동일해야 한다.

4. **핵심 편집 정확성 완결**
   - 삽입·덮어쓰기·리플·롤·슬립·슬라이드·속도·중첩의 프레임 정확성을 보장해야 한다.
   - 링크·그룹·트랙 잠금·마커·자막·오디오 자동화가 편집 후 어긋나지 않아야 한다.
   - 모든 파괴적 편집은 Undo/Redo로 완전히 복원돼야 한다.

5. **미리보기와 출력 일치 완결**
   - 컷, 트랜지션, 색상, 마스크, 속도, 자막, 오디오 결과가 미리보기와 최종 파일에서 일치해야 한다.
   - 출력 범위, 중첩 의존성, 대기 작업 스냅샷, 취소·재개·재시도가 올바르게 동작해야 한다.
   - 강제 종료 후 복구한 파일에도 프레임 누락, 중복, 오디오 단절이 없어야 한다.

6. **기본 안정성 완결**
   - 장시간 편집 중 무한 로딩, UI 멈춤, 메모리 누수, 미디어 핸들 유실, 저장 실패를 제거해야 한다.
   - 오류가 발생해도 프로젝트와 원본 파일을 훼손하지 않고 복구 안내를 제공해야 한다.

7. **배포 안전성 완결**
   - Windows 서명 설치·제거·업데이트와 macOS 서명·공증·설치를 완료해야 한다.
   - 운영 업데이트와 충돌 수집 서비스의 도메인, TLS, 키, 저장소, 개인정보 정책을 연결해야 한다.

### P1 — 전문 편집기 완성도 작업

- 다중 코덱·VFR·10-bit·HDR·멀티채널 오디오 호환 범위 확장
- 대용량·장시간 프로젝트의 재생, 탐색, 캐시, 메모리, 백그라운드 작업 최적화
- 색상 관리·스코프·HDR·오디오 loudness의 기준 정확도 강화
- 멀티캠, 프록시, 자막, ADR, 쇼츠, 교환 포맷의 실무 예외 처리
- 키보드 중심 편집, 패널 포커스, 다중 모니터, 사용자 작업공간, 접근성 개선
- 충돌 진단, 자동 복구, 진단 로그 내보내기와 고객 지원 흐름 완성

### P2 — Premiere Pro 동급 범위를 넓히는 작업

- 제3자 영상·오디오 플러그인과 확장 패널 SDK
- Adobe/After Effects 계열 작업 흐름과 더 높은 교환 호환성
- AAF/OMF와 전문 후반 제작·방송 교환 포맷
- 전문 카메라 RAW, 외부 모니터링, 캡처 장치, 제어 표면 지원
- 인터넷 기반 팀 프로젝트, 권한, 변경 이력, 검토 서비스
- 템플릿·효과·확장 기능 마켓과 제작자 생태계

P2가 모두 없다고 해서 독립 편집기로 출시할 수 없는 것은 아니다. 다만 **Premiere Pro와 기능·생태계까지 동급**이라고 표현하려면 P2 영역도 상당 부분 필요하다.

## 전체 출시 완료 선언 조건

아래 조건을 모두 만족해야 `개발 완료` 또는 `전체 출시 준비 완료`라고 표시한다.

1. 사용자 보고 핵심 차단 문제에 미해결 항목이 없다.
2. 가져오기 → 정리 → 편집 → 저장·재열기 → 출력의 전체 흐름이 실제 프로젝트에서 끊기지 않는다.
3. 지원한다고 표기한 컨테이너·코덱·색상·오디오 조합의 호환 범위와 제한 사항이 문서화돼 있다.
4. 미리보기와 최종 출력 결과가 허용 오차 안에서 일치한다.
5. 장시간·대용량 프로젝트의 안정성과 복구가 출시 기준을 충족한다.
6. 설치 파일이 서명되고, 업데이트·제거·복구가 안전하다.
7. macOS를 지원 대상으로 표기한다면 서명·공증된 실기기 결과가 있다.
8. 개인정보, 라이선스, 오픈소스 고지, 충돌 보고, 업데이트 운영 정책이 준비돼 있다.
9. 알려진 제한 사항과 지원하지 않는 기능을 사용자 문서에 명확히 공개한다.
10. 모든 필수 항목에 소스 존재가 아니라 재현 가능한 완료 근거가 있다.

## 개발 재개 시 권장 순서

1. 미디어 로딩과 MOV 호환 경로를 최우선으로 완결한다.
2. 미디어 삭제·이동과 프로젝트 재열기까지 자산 관리 흐름을 완결한다.
3. 핵심 편집·Undo/Redo·중첩·속도·오디오 동기화의 데이터 무결성을 완결한다.
4. 미리보기와 출력 일치를 완결하고 렌더 큐·복구를 닫는다.
5. 장시간·대용량·전문 코덱 성능과 안정성 문제를 해결한다.
6. Windows/macOS 서명 패키지와 운영 업데이트·충돌 수집을 연결한다.
7. 제품 문서, 제한 사항, 라이선스, 개인정보, 지원 체계를 마무리한다.
8. 그 후 Premiere Pro 대비 P2 생태계 격차를 우선순위에 따라 확장한다.

## 최종 요약

Cutline은 기능이 거의 없는 초기 프로토타입은 아니다. 전문 편집기의 핵심 영역이 폭넓게 구현된 대형 소스 상태다. 하지만 사용자에게 가장 기본적인 미디어 로딩·정리 흐름에서 실패가 있었고, 수정 후 실제 동작이 아직 확정되지 않았으므로 현재는 출시 가능 상태가 아니다.

앞으로의 기준은 V1이나 V2가 아니라 이 문서의 P0 전체와 출시 완료 조건이다. 기능 수를 더 늘리는 것보다 먼저 기본 흐름의 실패를 없애고, 프로젝트 무결성·출력 일치·배포 안전성까지 닫아야 전체 출시로 볼 수 있다.
