# 12. Top-tier 완성 실행 계획

## 목적

`20260814경쟁 비교표.md`의 비교 항목을 실제 개발 Epic, 정량 완료 기준, 자동 검증 명령으로 전환한다. “기능이 소스에 존재함”이 아니라 반복 가능한 증거가 있을 때만 완료로 판정한다.

## 실행 원칙

1. E1 출시 신뢰성 게이트를 통과하기 전에는 새로운 효과·템플릿·생성형 AI 범위를 늘리지 않는다.
2. 각 Epic은 기능 구현, 자동 회귀, 실물 픽스처, 사용자 작업 검증을 모두 가져야 한다.
3. Cutline은 AI 대본 편집, 롱폼→쇼츠, Creator Source Graph, 로컬 AI 통제를 최상으로 만든다.
4. 정밀 편집·색상·오디오·포맷은 지원 범위를 명시하고 그 범위 안에서 상용 강함을 먼저 달성한다.
5. 비교표 점수는 코드 양이 아니라 마지막으로 통과한 재현 가능한 증거를 반영한다.

WebView가 6채널 AAC 또는 HEVC Main10을 직접 지원하지 않는 환경에서도 연속 WAV/원시 10-bit 체크포인트와 번들 코덱 엔진의 원자적 mux·인코딩 경로를 사용한다. 설치본은 아직 Authenticode `NotSigned`이고 실제 카메라 HDR/VFR 기준셋·캘리브레이션 모니터 계측·macOS 검증이 남아 있어 외부 배포 완료가 아니라 로컬 설치본 실출력 검증 완료로 판정한다.

2026-08-15에는 `release/check-commercial-readiness.mjs`를 추가해 남은 외부 조건을 하나의 기계 판독 게이트로 고정했다. 로컬 `F:\Download Files`의 HDR 표기 후보 3개는 모두 640×272 H.264 8-bit BT.709 CFR이므로 실물 HDR/VFR 증거에서 제외했다. 현재 작업 환경에는 적격 실물 원본·서명 인증서·macOS/기준 모니터/운영 영수증이 없으며, 게이트는 이를 `blocked`로 정확히 보고한다.
